# Security Policy

## Supported versions

Security support focuses on the current `main` branch and the
[latest released version](https://github.com/NikolayAir/OrbiRig/releases/latest).
Earlier releases may not receive security updates.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/NikolayAir/OrbiRig/security/advisories/new)
to send a private report. You can also find it under **Security → Report a vulnerability**
in the repository. Please do not open a public issue for a suspected vulnerability.

When applicable, include:

* the affected commit or version;
* a concise description of the vulnerability and its potential impact;
* steps to reproduce the issue or a proof of concept;
* relevant environment or configuration details.

Please do not publish vulnerability details until the report has been reviewed
and there has been a reasonable opportunity to address the issue.
